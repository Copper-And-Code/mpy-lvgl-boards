    Build commands¶

    scripts/build_rp2.sh does all of this with the pins above (sources in .work/ unless WORK_DIR is set). By hand, in the workspace:

    export PATH=$PWD/tools/xpack-arm-none-eabi-gcc-15.2.1-1.1/bin:$PATH
B=$PWD/copper-and-code-mcu-boards/boards/rp2/WAVESHARE_RP2350_TOUCH_LCD_4

# with LVGL (default manifest; omnipython-lvgl beside copper-and-code-mcu-boards, or
# LVMP_DIR=<omnipython-lvgl>/ports/micropython)
make -C micropython/ports/rp2 BOARD_DIR=$B BUILD=build-TLCD4 -j

# bring-up build without LVGL
make -C micropython/ports/rp2 BOARD_DIR=$B BUILD=build-TLCD4-nolvgl FROZEN_MANIFEST=$B/manifest_nolvgl.py -j

    MicroPython 1.29 takes the LVGL C module from the manifest (include("$(LVMP_DIR)/manifest.py"), which calls c_module(".")), not from USER_C_MODULES. LVMP_DIR reaches the manifest as the CMake variable MICROPY_MANIFEST_LVMP_DIR, set in mpconfigboard.cmake.
