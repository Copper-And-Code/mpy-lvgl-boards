    copper-and-code-mcu-boards¶

    MicroPython and LVGL firmware for microcontroller boards with a touch screen. Flash the board, then import display_driver: the display, the touch and LVGL are running, and the same program works on every board here. Write the GUI in Python, run it with mpremote or Thonny, or design it in Copper and Code Studio and upload it from there.

    Download

    Ready images for every board in the releases, with their SHA-256 sums.

    One driver, every board

    WIDTH, HEIGHT, start(), stop(), backlight() and what a Ctrl-C does are the same everywhere: the display_driver contract.

    Upstream, unchanged

    MicroPython 1.29 and omnipython-lvgl as they are: out-of-tree boards and C modules, no fork.

    Start¶

    1. Download the image for your board from the latest release.
    2. Flash it: the RP2350 takes the .uf2 on its USB drive; the STM32 boards with DFU; the ESP32-4848S040 with esptool.
    3. Run an example:
    import display_driver
import lvgl as lv

label = lv.label(lv.screen_active())
label.set_text("Hello")
label.center()

    The program can end there: display_driver keeps LVGL running from a timer.

    Building¶

    scripts/build.sh <port> <BOARD> [VARIANT] fetches the pinned sources and toolchain and writes the firmware into dist/: see Building and the repository.
