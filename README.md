# mpy-lvgl-boards

MicroPython + LVGL firmware for boards that upstream MicroPython does not cover, built as
out-of-tree boards and user C modules: no fork of MicroPython or of the LVGL binding
([PyDevices lvgl-micropython](https://github.com/PyDevices/lvgl-micropython)).

Every board ships a frozen `display_driver.py`, so `import display_driver` is all an
application needs, e.g. code generated by
[lvgl-mpy-builder](https://github.com/Copper-And-Code/lvgl-mpy-builder).

| Board | MCU | Display | State |
|---|---|---|---|
| [Waveshare RP2350-Touch-LCD-4](boards/rp2/WAVESHARE_RP2350_TOUCH_LCD_4/README.md) | RP2350B | 4" 480x480 RGB (ST7701S), GT911 touch | works at 240x240 (no PSRAM), see README |

## Build

```bash
scripts/build.sh <port> <BOARD> [VARIANT]   # pinned sources and toolchain in .work/,
                                            # patches/ applied, firmware in dist/
scripts/build.sh rp2 WAVESHARE_RP2350_TOUCH_LCD_4   # same as scripts/build_rp2.sh
```

## Layout

```text
boards/<port>/<BOARD>/   board definitions (BOARD_DIR)
modules/                 user C modules (rgbpanel: RGB panel scan-out with PIO + DMA)
python/                  frozen drivers (display_driver.py, gt911.py)
examples/                small LVGL examples to run with mpremote
scripts/                 build scripts
patches/<project>/       patches to the pinned external sources, applied by scripts/build.sh
tests/hil/               tests run on the board with mpremote; tests/host/ on the unix port
docs/                    measurements, logs (docs/log/), credits, drafts
```
